# Style samples

This directory is the working library for converting logical structure masks
into an approved ASCII construction vocabulary.

Edit `catalog.json` to add or classify geometry. Put handcrafted reference art
in `targets/`. Run `python style_sample_system.py` from the repository root to
rebuild `output/`.

The three-column review sheet shows:

1. the logical occupied-cell mask;
2. the disposable automatic draft;
3. the preserved handcrafted target, when present.

See `../STYLE_SAMPLE_WORKFLOW.md` for review states and promotion rules.
